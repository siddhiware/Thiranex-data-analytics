# Thiranex Data Analytics Internship

This repository contains my projects completed during my Data Analytics Internship at Thiranex.

## Projects

### Task 1 — Sales & Revenue Analysis Dashboard

* Analyzed sales and revenue data
* Calculated key performance indicators (KPIs)
* Analyzed product and regional performance
* Created visualizations using Python

### Task 2 — Customer Segmentation

* Performed customer analysis
* Used RFM features for customer behavior analysis
* Applied K-Means clustering
* Visualized customer segments

### Task 3 — Predictive Analytics Using Historical Data

* Cleaned historical sales data
* Built a predictive model using Python
* Evaluated model performance
* Generated future sales forecasts
* Visualized actual and predicted values

### Task 4 — Data Cleaning & Reporting Automation

* Identified missing values
* Removed duplicate records
* Standardized inconsistent data
* Converted data types
* Generated automated summary and monthly reports
* Created visual summaries
